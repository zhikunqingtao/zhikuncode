现`evidence/java/reproduce.md`的命令直接引用已有`source-head/source-parent`，末尾只说“已完成archive”，没有新读者的解包和复制探针步骤。若不提交这两个目录，必须在发布候选包补以下初始化流程（下列为示例，不是本次已执行操作）：

```bash
# bash；在评审结果_20260925_v1目录内执行；SOURCE_REPO指向含两个commit的源码仓库
set -euo pipefail
JAVA_EVIDENCE="$PWD/evidence/java"
```
